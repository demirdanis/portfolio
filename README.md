## Getting Started

First, run the development server:

```bash
npm run dev
```

## Deploy

```bash
DEPLOY_TARGET=gh-pages NEXT_PUBLIC_BASE_PATH="" npm run predeploy
DEPLOY_TARGET=gh-pages NEXT_PUBLIC_BASE_PATH="" npm run deploy 
```

## Blog Yazısı Ekleme

Yeni blog yazısı eklemek için [BLOG_EKLEME_KILAVUZU.md](./BLOG_EKLEME_KILAVUZU.md) dosyasındaki adımları takip edin.
